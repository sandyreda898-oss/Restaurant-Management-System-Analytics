# Restaurant Management System Dashboard
A complete restaurant analytics and management project built using SQL Server, Python, and Streamlit.
## Project Overview
This project simulates a real-world restaurant management system including:
- Customer Management
- Orders & Payments Tracking
- Delivery Performance
- Inventory Monitoring
- Revenue & Profit Analysis
- Employee & Salary Analysis
- Customer Reviews Analytics
## Technologies Used
- SQL Server
- Python
- Streamlit
- Pandas
- Plotly
- PyODBC

## Database Features
- Relational database design
- Multiple normalized tables
- Dummy data generation (1000+ records)
- Advanced SQL queries for business insights

## Dashboard Features
- KPI Metrics
- Revenue Analysis
- Order Status Tracking
- Payment Analysis
- Top Selling Menu Items
- Inventory Monitoring
- Delivery Performance
- Customer Insights

## Key Business Insights
- Revenue distribution by category
- Top-performing menu items
- Customer loyalty analysis
- Delivery employee performance
- Inventory reorder monitoring
